# AI使用情况说明
内训选题的部分，选题背景和可能遇到的问题基本由我思考。课程目标由我与AI讨论后得出。对于题目的相关知识和信息，例如YOLO模型、模型训练、要用的软件等几乎全部依靠AI搜集。但我去手动确认了一下AI给出的结果是否是一个成熟的、大众化的方案。

PPT部分，我最初让AI帮我搜索并整理了关于ROS的基础知识，我在其中选取了相对简单但相对重要的部分内容，并且补充了“我的代码写在哪”这个部分，因为我觉得这对于听众对依赖ROS的整个项目的整体理解有挺大帮助的。而关于具体名词是否准确、AI给出的信息流是否合理等我都亲自核查过。最后，PPT是我让AI根据我修改过的讲义，用一种很简洁的风格（三种颜色+基本图形）生成的。虽然讲义逻辑还算顺畅，但但AI生成的PPT逻辑有点乱，所以我又手动改了一些章节顺序，并适当加了一些元素便于听众理解。

最后，git的操作基本是问AI我该干什么，有哪些步骤不可少，哪些可以跳这类问题学的，具体操作由我在Bash里完成。
